# 🎮 POKÉMON: KIZIL ZÜMRÜT v2.0 (Mega Evolution & Ultimate GBA Edition)

Tarayıcıda doğrudan oynanabilen, **Pokémon Red / FireRed & LeafGreen** çekirdeği üzerine **tüm Game Boy Advance (GBA) Pokémon oyunlarının** ve **en ünlü modern GBA ROM-Hack mekaniklerinin** (*Radical Red*, *Pokémon Unbound*, *Emerald Imperium*, *Modern Emerald*, *Theta Emerald EX*) birleştirildiği kapsamlı Türkçe Pokémon RPG oyunu!

---

## 💎 v2.0 Büyük Güncelleme: Mega Evrim, İlkel Dönüşüm & Akın İnleri!

1. **31 Tam Mega Evrim & İlkel Dönüşüm (Primal Reversion)**
   - *Mega Venusaur, Mega Charizard X, Mega Charizard Y, Mega Blastoise, Mega Beedrill, Mega Pidgeot, Mega Alakazam, Mega Slowbro, Mega Gengar, Mega Kangaskhan, Mega Pinsir, Mega Gyarados, Mega Aerodactyl, Mega Mewtwo X, Mega Mewtwo Y, Mega Ampharos, Mega Steelix, Mega Scizor, Mega Heracross, Mega Houndoom, Mega Tyranitar, Mega Sceptile, Mega Blaziken, Mega Swampert, Mega Gardevoir, Mega Aggron, Mega Manectric, Mega Altaria, Mega Absol, Mega Salamence, Mega Metagross, Mega Rayquaza* ve **İlkel Kyogre / İlkel Groudon**!
   - Savaşta **SAVAŞ** menüsünde beliren **✨ MEGA EVRİM** anahtarı, gökkuşağı dönüşüm aurası, anlık tür/yetenek/+100 temel istatistik değişimi ve **Mega Boss Yapay Zekâsı** (Giovanni, Bruno, Agatha, Lance, Şampiyon Blue, Anabel ve Noland kendi as Pokémonlarını Mega Evrimleştirir!).
   - *Mega Rayquaza*, *Ejder Yükselişi (Dragon Ascent)* hamlesini bildiğinde Mega Taşa ihtiyaç duymadan evrimleşir ve tutulan eşya slotunu özgürce kullanır!
2. **18. Tür: Peri (Fairy) & Yeni İmza Hamleler**
   - Tam 18x18 tür tablosu, *Clefairy, Clefable, Ralts, Kirlia, Gardevoir, Mega Altaria* tür güncellemeleri ve *Ay Patlaması (Moonblast)*, *Sert Oyun (Play Rough)*, *Parıltılı Işık (Dazzling Gleam)*, *Uçurum Kılıcı (Precipice Blades)*, *Köken Nabzı (Origin Pulse)* ve *Ejder Yükselişi (Dragon Ascent)* hamleleri!
3. **12 Yeni Mega / İlkel Yetenek**
   - *Sert Pençe (Tough Claws)*, *Mega Fırlatıcı (Mega Launcher)*, *Ebeveyn Bağı (Parental Bond — 2 vuruş!)*, *Peri Derisi (Pixilate)*, *Göksel Deri (Aerilate)*, *Sihirli Ayna (Magic Bounce)*, *Kalıp Kıran (Mold Breaker)*, *Uyum Yeteneği (Adaptability)*, *Filtre (Filter)*, *İlkel Deniz (Primordial Sea)*, *Issız Toprak (Desolate Land)* ve *Delta Akımı (Delta Stream)*!
4. **Dinamaks / Alfa Akın İnleri (Raid Dens) & Harika Takas (Wonder Trade)**
   - Üst menüdeki **✨ Mega & Akın** merkezinden **2.2x Canlı Alfa Raid Boss** savaşlarına gir (%45 HP kalkanı kırıldığında yakalanabilir!), garantili **Mega Taş + Nadir Şeker + BP** ödüllerini topla veya **Harika Takas** ile %12 Shiny şanslı sürpriz Pokémonlar kazan!
5. **Yeni QoL Sistemleri**
   - Takım ekranında **Ücretsiz Hamle Hatırlatıcı (Move Relearner)**, **Yetenek Kapsülü (Ability Capsule)** ve **Hayat Küresi (Life Orb)**!

## 🌐 GitHub Pages ile Yayınlama (Canlı Link)

Bu repo `.github/workflows/deploy-pages.yml` ve göreli Vite taban yolu (`base: './'`) ile tam **GitHub Pages** uyumludur:

1. GitHub reponuzda **Settings → Pages** sekmesine gidin.
2. **Build and deployment → Source** açılır menüsünden **`Deploy from a branch` yerine `GitHub Actions`** seçeneğini seçin.
3. `Deploy to GitHub Pages` iş akışı otomatik olarak Vite projesini derleyip `https://<kullanici-adi>.github.io/<repo-adi>/` adresinde yayınlayacaktır!
